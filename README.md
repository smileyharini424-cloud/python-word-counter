# Word Counter

## Explanation

This program counts the number of words entered by the user.

## Problem Statement

Write a Python program that accepts a sentence and counts the total number of words.

## Features

* Accepts a sentence
* Splits text into words
* Counts the words
* Displays the total

## How It Works

The input sentence is divided into words using the `split()` method. The length of the resulting list gives the word count.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `len()`

## Program Flow

1. Start
2. Read a sentence
3. Split the sentence into words
4. Count the words
5. Display the count
6. End

## Sample Input

```text
Python is easy to learn
```

## Sample Output

```text
Number of words: 5
```

## Time Complexity

## Space Complexity
